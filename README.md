Lab 6

Open the maps in the deliverables folder:
- index.html: top 10 gross outflows from Cook County.
- bonus.html: top 10 net gains to Cook County from outside Illinois.
- map6.html: the tutorial map.

Keep each map with its data JS file and CanvasFlowmapLayer.js. Internet access
is needed for the map background and hosted libraries. The GeoJSON files can
also be opened in QGIS.

The data comes from the Census Bureau's 2016-2020 ACS. Some migration values
were missing from the lab shapefile, so the matching Census table was used
to fill them in. The saved source files are in source-data.

I originally prepared and exported data in QGIS.

I used ChatGPT to ask questions about the data, flow direction, labels, and
legend. It also helped put together and helped troubleshoot the map code with errors along the way.

Data source:
https://www.census.gov/data/tables/2020/demo/geographic-mobility/county-to-county-migration-2016-2020.html
